# Orchestrated Roadmap Builder

Use this skill when Jenn wants a large roadmap or campaign built through multiple agents, models, providers, machines, or chats. Preserve the original ambition. A worker receives a complete roadmap-sized outcome; phase gates live inside the packet and do not justify stopping after each phase.

## Operating Loop

1. Locate the authoritative roadmap, current structured tracker, source revision, owner boundaries, and existing relevant proof. Planning files never count as implementation evidence.
2. Express the campaign as a validated manifest with dependencies, disjoint owned outputs, prohibited paths, target rules, evidence policy, and a `MUST FIRE` plus `MUST STAY SILENT` bar for every phase.
3. Compile only dependency-ready, collision-safe roadmaps. Retarget each packet to its isolated worktree so all input and output paths are exact on the worker's machine.
4. Route using measured capability for the task shape. Do not claim a universal model winner. Sol keeps architecture, integration, conflict resolution, and verification authority; human owners keep protected acceptance and promotion authority.
5. Dispatch workers without inherited conversation and without child-worker permission. Give each worker only its committed brief, exact workspace, owned outputs, focused acceptance checks, and bounded return contract.
6. Lease the roadmap, record lifecycle transitions atomically, and recover only expired work. A worker result enters review; it never verifies itself.
7. Audit source identity and changed-path scope, reuse current proof that still satisfies unchanged gates, rerun only invalidated checks, then integrate worker commits and prove their composition.
8. Update structured state after each accepted transition, regenerate the dashboard, and publish committed durable artifact pointers to Riff. Riff coordinates discovery and never grants canonical authority.

## Required Behavior

- Continue all safe, independent roadmap work when one lane encounters an external gate.
- Treat missing credentials, unavailable physical machines, destructive owner decisions, and required human acceptance as specific gates. Do not manufacture approvals or broad revalidation work.
- Use at most the campaign correction budget for a worker's conceptual misses; reroute or escalate afterward.
- Preserve worker observations, refusals, discarded framings, and useful sparks in evidence or emergence records without turning speculation into roadmap completion.
- Finish only when no executable unverified roadmap remains and the dashboard equals structured state.
